## Critérios de Avaliação — Etapa 5

- [ ] **(Nível A)** Todos os campos de formulário possuem rótulos (`<label>`) visíveis e associados no código, com identificação clara dos campos obrigatórios.
- [ ] **(Nível AA)** Campos que coletam dados pessoais do usuário (nome, e-mail, telefone, senha, endereço) indicam corretamente sua finalidade no código (`autocomplete`).
- [ ] **(Nível A)** Erros de preenchimento são identificados automaticamente e descritos em texto próximo ao campo afetado (sem revelar dados sensíveis), movendo o foco para ajudar na localização.
- [ ] **(Nível AA)** Quando um erro de entrada é detectado, o sistema oferece sugestões claras de como corrigi-lo.
- [ ] **(Nível AA)** Em transações jurídicas, financeiras ou de alteração/exclusão de dados, é possível reverter o envio, revisar os dados ou confirmar antes de finalizar.
- [ ] **(Nível AAA)** Todos os formulários do site permitem revisão e confirmação antes do envio e contam com ajuda contextual disponível.
- [ ] **(Nível A)** Não exigir que o usuário digite novamente informações já fornecidas na mesma sessão ou etapa (preenchimento automático ou seleção dos dados já informados).
- [ ] **(Nível AA)** Processos de login e autenticação não dependem de memorização ou desafios cognitivos (permitir colar senha e usar gerenciadores de senhas) e são 100% operáveis por teclado.
- [ ] **(Nível AA)** O login e as demais etapas de autenticação não podem exigir testes cognitivos, como memorizar, resolver quebra-cabeças ou transcrever códigos, salvo com alternativa que dispense esse esforço.
- [ ] **(Nível A)** Desafios de segurança (como CAPTCHA) possuem alternativas acessíveis para diferentes percepções sensoriais (sem áudio ruidoso ou imagens sem contraste).
- [ ] **(Nível A)** Caso ocorra erro de login ou segurança, o usuário consegue corrigir os dados sem perder o que já havia preenchido.
- [ ] **(Nível A)** Focar em um elemento ou alterar o valor de um campo não dispara mudanças inesperadas de contexto (não envia o formulário nem abre nova janela sozinho sem aviso prévio). Links que abrem nova janela informam isso ao usuário.
- [ ] **(Nível AA)** Manter elementos que se repetem (menu de navegação, campo de busca e botões de ajuda) na mesma posição e ordem relativa em todas as páginas, identificando componentes de mesma função de forma padronizada.
- [ ] **(Nível A)** Links de ajuda (contato, FAQ, chat) devem estar sempre na mesma posição em todas as páginas do site.
- [ ] **(Nível AA)** Componentes com a mesma função em todo o site devem ter o mesmo nome e o mesmo ícone.
- [ ] **(Nível A)** Se houver limite de tempo na página, o usuário pode desativá-lo antes, ajustá-lo em até 10x o valor padrão ou estendê-lo com ação simples (recebendo aviso com pelo menos 20 segundos de antecedência).
- [ ] **(Nível AAA)** A aplicação não impõe limites de tempo para uso ou teclado, permite adiar alertas/interrupções não emergenciais e preserva todos os dados preenchidos caso a sessão expire (avisando se houver expiração com menos de 20 horas).
