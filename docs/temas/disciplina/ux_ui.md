## Qual a diferença?

| | **UX (Experiência do Usuário)** | **UI (Interface do Usuário)** |
| :--- | :--- | :--- |
| **Foco** | A jornada completa e o quão fácil e útil ela é | Aparência e interação dos elementos na tela |
| **Pergunta** | A pessoa consegue resolver o seu problema? | A tela é clara, legível e agradável? |
| **Entregas típicas** | Pesquisas, personas, fluxos, protótipos | Cores, tipografia, botões, ícones, layout |
| **Analogia** | A planta e a lógica de uma casa | O acabamento e a decoração |

## Princípios visuais de UI

- **Hierarquia:** o que é mais importante deve se destacar em tamanho, cor e posição.
- **Consistência:** componentes iguais se comportam e parecem iguais.
- **Contraste e legibilidade:** o texto precisa ser fácil de ler em qualquer condição.
- **Espaçamento e alinhamento:** o espaço em branco organiza e dá respiro.
- **Feedback:** toda ação do usuário gera uma resposta visível.

## UX, UI e acessibilidade

Boas práticas de acessibilidade são parte do bom design: contraste mínimo de 4,5:1 para texto comum e alvos de toque de pelo menos 44 x 44 px são exemplos que aparecem no nosso [checklist](../../checklist/etapa4.md).
